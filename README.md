# Lending System - How to Open the Pages

This project includes three different entry points:

- Public Borrower Landing Page
- Admin Login Page
- Collector Login Page

## 1. Open the Public Landing Page (Client/Borrower)

1. Make sure XAMPP or your local PHP server is running.
2. Open your browser.
3. Go to:

   http://localhost/lending_system/lending_system/index.php

This will open the public landing page for RJ and RR Finance Services.

## 2. Open the Admin Login Page

1. In your browser, go to:

   http://localhost/lending_system/lending_system/login_lending.php

2. Use your admin credentials to sign in.

## 3. Open the Collector Login Page

1. In your browser, go to:

   http://localhost/lending_system/lending_system/login_lending.php

2. Log in using collector credentials.

> The same login page is used for both Admin and Collector. Access is determined by the user role after login.

## 4. Open the Registration Page

If you want to open the borrower registration page directly, visit:

http://localhost/lending_system/lending_system/registration_lending.php

## Troubleshooting

- If the page does not load, check that Apache is running in XAMPP.
- If you see a blank page or error, check the PHP error logs.
- Make sure the project folder is inside the XAMPP htdocs directory.

## Project Folder

The project is located at:

C:\xampp\htdocs\lending_system\lending_system
